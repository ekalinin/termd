# Color themes

A theme colors headings, [links](https://github.com/ekalinin/termd#themes), `inline code`, list markers, alerts, tables and code.

- Select a theme with `--theme` or `TERMD_THEME`
- Light themes: `solarized-light`, `gruvbox-light`, `catppuccin-latte`

> [!NOTE]
> Paragraph text keeps the color of the terminal.

> [!WARNING]
> A named theme does not adapt to the background.

| Theme | Background |
|---|---|
| `dark`, `light` | any |
| `dracula`, `nord` | dark |
